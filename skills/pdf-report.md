# 结构化报告撰写手册

## 三段式工作流程

### 第一段：先列大纲，不要直接开写

把报告的骨架列出来（标题 + 3-6 个一级小节 + 每节一句话说明写什么），然后**停下来**问用户"这个结构可以吗"。

**为什么必须停**：结构错了，写三页也是白写；改大纲一分钟，改三页半小时。这是整份报告里最省时间的一步。只有用户明确说"不用问直接写"才跳过。

### 第二段：逐节填充

- 一次写完一节再动下一节，不要跳来跳去。
- 每个数字、每条结论都要能追溯到"材料里的哪一句"。**材料里没有的信息，标成「待补充」，不许编。**
- 材料之间打架时，把冲突**写进报告**（"A 材料说 12，B 材料说 15，差异待核"），不要悄悄选一个顺眼的。
- 引用原始数据时带上口径（哪个时间段、什么单位、怎么统计的）。

### 第三段：写完自查

1. 每条结论都能在正文里找到支撑吗？
2. 有没有漏掉反例、异常值、反面证据？（只写支持自己结论的部分 = 有偏报告）
3. 标了「待补充」的地方有没有交代清楚？
4. 摘要里说的和正文一致吗？

## 报告骨架

```
# 标题：结论先行，不要写成"关于……的报告"

## 摘要
3-5 句：结论 + 最主要的两三条依据 + 最大的不确定性。

## 背景与范围
为什么做这份报告、覆盖什么、**明确不覆盖什么**。

## 发现
按重要性排序。每条写：发现 → 证据 → 影响。

## 风险与不确定性
已知的坑、数据缺口、依赖的假设。

## 建议
可执行的动作。写上负责人/时间更好。

## 附录
原始数据、出处、口径说明。
```

## 注意事项

- **结论先行**：读者只读摘要就应该能做决定。
- **区分事实与推测**：推测必须写明"这是推测，依据是……"。
- **口径统一**：同一份报告里单位、时间范围、统计方式必须一致；不一致就在附录里说明原因。
- 报告不是越厚越好：**能一页说清就别写三页**。凑长度是最容易被看穿的。
